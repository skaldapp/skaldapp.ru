## ❓ Вопрос — ответ

🤔 **Чем Skald отличается от других редакторов Markdown?**

В Skald вы пишите тексты, а не программируете. Skald автоматически превращает тесты в вебсайт. Публикация не требует отдельного процесса сборки: структура, которую вы видите в редакторе, — это и есть финальный продукт.

🤔 **Что можно сделать с помощью Skald?**

Создавать и организовывать любой древовидный контент: от личных заметок и черновиков книг до технической документации и баз знаний. Skald — это гибкий инструмент для работы с текстом, который может быть как простым блогом, так и сложным веб-приложением.

🤔 **Как посмотреть сайт в браузере на этапе разработки?**

Есть много способов. Если вы с компьютером на короткой ноге, то воспользуйтесь советом с официального сайта Vue.js:

> Для запуска локального HTTP-сервера установите Node.js, затем выполните команду `npx serve` в каталоге с проектом. Можно использовать и любой другой HTTP-сервер, поддерживающий статические файлы с правильными MIME-типами.

Более простой способ — программа [Simple Web Server](https://simplewebserver.org/ru/). Она бесплатна, кроссплатформенна и позволяет запустить локальный сервер за пару кликов.

🤔 **Кроме файловой системы, с какими системами хранения работает Skald?**

Помимо локальной файловой системы, Skald поддерживает любые S3-совместимые облачные хранилища: AWS S3, MinIO, Cloudflare R2, DigitalOcean Spaces и другие. При подключении данные шифруются, поддерживается работа с несколькими аккаунтами и защита доступа через PIN-код.

🤔 **Может ли хранилище S3 выступать в качестве статического хостинга?**

Да, большинство S3-совместимых хранилищ (AWS S3, Cloudflare R2, DigitalOcean Spaces) поддерживают режим статического веб-хостинга. Достаточно включить опцию в настройках бакета — и его содержимое станет доступно по публичному URL. Skald умеет работать с S3-совместимыми хранилищами напрямую - сайт сразу доступен в интернете без дополнительного копирования.

🤔 **Можно ли использовать Skald офлайн?**

Да. Electron-версия обеспечивает полноценную автономность с нативным доступом к файловой системе. Браузерная версия также работает без подключения после первоначальной загрузки кэша.

Функции, требующие интернет (синхронизация с S3, AI-интеграция), при офлайн-работе временно недоступны, однако все базовые операции — редактирование, сохранение, навигация — функционируют полностью автономно.

🤔 **Безопасно ли добавлять секретные ключи в Skald?**

Skald применяет базовые меры защиты: ключи сохраняются в зашифрованном виде, доступ к S3-ключам может быть защищён PIN-кодом. Однако, поскольку приложение работает на стороне клиента, ключи хранятся в локальном хранилище вашего устройства.

Рекомендации:

* Не используйте ключи с неограниченными правами

* Регулярно отслеживайте их использование

* Активируйте локальную защиту через PIN-код

* Используйте ключи только на доверенных устройствах

🤔 **Какие операционные системы поддерживает Skald?**

Skald работает на всех основных платформах:

* **Браузерная версия**: Chrome, Firefox, Edge, Safari на Windows, macOS, Linux, ChromeOS и мобильных устройствах

* **Electron-версия**: нативные сборки для Windows, macOS и Linux с прямым доступом к файловой системе

Все ключевые функции доступны независимо от ОС и способа запуска.

🤔 **Какие модели ИИ поддерживает Skald?**

Skald реализует поддержку протокола OpenAI, что позволяет подключать любые совместимые модели. Интеграция обеспечивает работу следующих функций:

* Генерация контента;

* Умное автодополнение текста и кода;

* Интерактивный чат-помощник.

🤔 **Нужен ли Node.js для работы Skald?**

Нет. Редактор полностью функционирует на стороне клиента: компиляция Vue-компонентов, обработка Markdown и генерация структуры сайта выполняются непосредственно в браузере.

Это позволяет начать работу мгновенно — без установки зависимостей, настройки окружения или запуска сборочных процессов.
