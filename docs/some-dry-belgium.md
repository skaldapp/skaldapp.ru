## Frontmatter в Skald

Frontmatter - это специальный раздел в верхней части файла Markdown, используемый для хранения метаданных документа. Он использует формат YAML и окружен тремя дефисами (`---`). Skald использует Frontmatter для управления поведением страницы, метаданными и другими параметрами при помощи библиотеки Unhead.

Вы можете получить доступ к метаданным через глобальный объект [{{ $frontmatter }}]{v-pre} в выражениях Vue, к примеру для текущей страницы это будет выглядеть так:

```

{{ $frontmatter }}

```

К примеру, если вы хотите получить доступ к заголовку страницы, вы можете использовать выражение: [{{ $frontmatter.title }}]{v-pre}, что незамедлительно выведет заголовок текущей страницы - **{{ $frontmatter.title }}**.

### Базовый синтаксис

```YAML

---
title: Title
description: Description
attrs:
  un-cloak: true
  class:
    - container
    - mx-auto
    - prose
    - prose-sm
    - sm:prose-base
    - dark:prose-invert
hidden: false
template: false
icon: twemoji:page-facing-up
---

# Заголовок моего документа

Здесь основное содержание документа...

```

## Оcновные поля

### Аттрибуты управления страницей

* **attrs** - массив аттрибутов контейнера страницы, обычно включает в себя аттрибут un-cloak для исключения эффекта FOAC и классы для стилизации

* **hidden** - скрывает страницу из навигации

* **template** - указывает, что страница является шаблоном, в которую можно добавлять RouterView

* **icon** - иконка страницы

### Метаданные страницы

* **title** - заголовок страницы

* **titleTemplate** - шаблон заголовка страницы (функция или строка с плейсхолдером %s)

* **templateParams** - параметры шаблона для динамических замен

* **base** - базовый URL для всех относительных URL на странице (в норме вычисляется автоматически и не требуется указывать вручную)

* **link** - массив объектов для определения ссылок на внешние ресурсы (например, favicon, стили, шрифты и т.д.)

* **meta** - массив объектов для определения метаданных страницы (например, описание, ключевые слова, Open Graph и т.д.)

* **style** - массив объектов для определения встроенных стилей на странице

* **script** - массив объектов для определения встроенных скриптов на странице

* **noscript** - массив объектов для определения содержимого, которое будет отображаться, если JavaScript отключен в браузере

* **htmlAttrs** - объект для определения атрибутов элемента `<html>`

* **bodyAttrs** - объект для определения атрибутов элемента `<body>`

### Дополнительные поля

Любые дополнительные поля, добавленные в frontmatter, будут использованы для определения метаданных страницы. Например, если вы добавите поле `description`, оно будет использоваться для определения мета-описания страницы, а поле `keywords` - для определения мета-ключевых слов.

```YAML

---
title: Полное руководство по Markdown
description: Комплексное руководство по изучению синтаксиса Markdown и лучших практик
keywords: markdown, учебник, руководство, синтаксис
---

```
