## ❓ Вопрос — ответ

🤔 **Чем Skald отличается от других редакторов Markdown?**\
Skald объединяет свободу текстового редактора и дисциплину структурированных данных. Вы работаете с древовидной иерархией документов в визуальном интерфейсе, а результат — будь то локальная заметка или публичная страница — всегда находится под вашим полным контролем. Публикация не требует отдельного процесса сборки: структура, которую вы видите в редакторе, — это и есть финальный продукт.

🤔 **Что можно сделать с помощью Skald?**\
Создавать и организовывать любой древовидный контент: от личных заметок и черновиков книг до технической документации и баз знаний. Skald предоставляет единое пространство для письма, структурирования и (при необходимости) публикации. Вы можете работать полностью офлайн, синхронизироваться с облаком или мгновенно выкладывать результат в сеть — выбор стратегии остаётся за вами.

🤔 **Как посмотреть сайт в браузере на этапе разработки?**\
Есть много способов. Если вы с компьютером на короткой ноге, то воспользуйтесь советом с официального сайта [Vue.js](https://ru.vuejs.org/guide/quick-start.html#splitting-up-the-modules):

> Для запуска локального HTTP-сервера установите [Node.js](https://nodejs.org/en/), затем выполните команду `npx serve` в каталоге с проектом. Можно использовать и любой другой HTTP-сервер, поддерживающий статические файлы с правильными MIME-типами.

Более простой способ — программа [Simple Web Server](https://simplewebserver.org/ru/). Она бесплатна, кроссплатформенна и позволяет запустить локальный сервер за пару кликов.

🤔 **Кроме файловой системы, с какими системами хранения работает Skald?**\
Помимо локальной файловой системы (через File System Access API), Skald поддерживает любые S3-совместимые облачные хранилища: AWS S3, MinIO, Cloudflare R2, DigitalOcean Spaces и другие. При подключении данные шифруются, поддерживается работа с несколькими аккаунтами и защита доступа через PIN-код.

В Electron-версии файлы сохраняются локально, что обеспечивает полноценную офлайн-работу без зависимости от браузерных ограничений.

🤔 **Может ли хранилище S3 выступать в качестве статического хостинга?**\
Да, большинство S3-совместимых хранилищ (AWS S3, Cloudflare R2, DigitalOcean Spaces) поддерживают режим статического веб-хостинга. Достаточно включить опцию в настройках бакета — и его содержимое станет доступно по публичному URL. Материалы из Skald можно публиковать напрямую: сайт сразу станет доступен в интернете без дополнительной настройки.

🤔 **Можно ли использовать Skald офлайн?**\
Да. Electron-версия обеспечивает полноценную автономность с нативным доступом к файловой системе. Браузерная версия также работает без подключения после первоначальной загрузки кэша.

Функции, требующие интернет (синхронизация с S3, AI-интеграция), при офлайн-работе временно недоступны, однако все базовые операции — редактирование, сохранение, навигация — функционируют полностью автономно.

🤔 **Безопасно ли добавлять секретные ключи в Skald?**\
Skald применяет базовые меры защиты: ключи сохраняются в зашифрованном виде, доступ к S3-ключам может быть защищён PIN-кодом. Однако, поскольку приложение работает на стороне клиента, ключи хранятся в локальном хранилище вашего устройства.

Рекомендации:

* Не используйте ключи с неограниченными правами

* Регулярно отслеживайте их использование

* Активируйте локальную защиту через PIN-код

* Используйте ключи только на доверенных устройствах

🤔 **Какие операционные системы поддерживает Skald?**\
Skald работает на всех основных платформах:

* **Браузерная версия**: Chrome, Firefox, Edge, Safari на Windows, macOS, Linux, ChromeOS и мобильных устройствах

* **Electron-версия**: нативные сборки для Windows, macOS и Linux с прямым доступом к файловой системе

Все ключевые функции доступны независимо от ОС и способа запуска.

🤔 **Какие модели ИИ поддерживает Skald?**\
Skald интегрируется с платформой **Mistral AI** и поддерживает совместимые с ней модели для:

* Генерации контента

* Умного автодополнения текста и кода

* Интерактивного чат-помощника

Требуется указать действующий API-ключ Mistral в настройках. Сервис доступен в России и предоставляет щедрый бесплатный тариф.

🤔 **Нужен ли Node.js для работы Skald?**\
Нет. Редактор полностью функционирует на стороне клиента: компиляция Vue-компонентов, обработка Markdown и генерация структуры сайта выполняются непосредственно в браузере.

Это позволяет начать работу мгновенно — без установки зависимостей, настройки окружения или запуска сборочных процессов.

🤔 **Использовался ли вайбкодинг при разработке Skald?**\
Нет, весь код написан вручную — это осознанное архитектурное решение. Ручная разработка обеспечивает полный контроль над логикой, предсказуемость поведения и высокую сопровождаемость.

Технический стек:

* TypeScript в строгом режиме (`strict: true`)

* `@vue/eslint-config-typescript` — строгая типизация для Vue

* `eslint-plugin-sonarjs` — выявление уязвимостей и сложных паттернов

* Prettier + `eslint-plugin-perfectionist` — форматирование кода

* Комплекс плагинов для линтинга стилей, манифестов, зависимостей

🤔 **Какие недостатки у Skald?**\
Skald выбирает простоту разработки и мгновенную обратную связь. Навигация по большим проектам происходит на стороне браузера. Для большинства сценариев (документация, блоги, базы знаний) это незаметно.

Если вы строите высоконагруженный публичный портал с миллионами посещений, возможно, стоит рассмотреть решения с серверным рендерингом — но тогда вы потеряете в простоте и скорости редактирования.
