# Skald

**Skald** — мощный и инновационный текстовый редактор с поддержкой **Markdown**, созданный для тех, кто ценит простоту, гибкость и безопасность. Он идеально подходит как для писателей, так и для разработчиков, предлагая кристально чистый и интуитивно понятный интерфейс, который помогает сосредоточиться на главном — творчестве и продуктивности.

## Особенности

- **Поддержка Markdown**: Полнофункциональный редактор с поддержкой стандартного и расширенного синтаксиса Markdown
- **Визуальный редактор**: WYSIWYG-режим для удобного редактирования текста
- **Поддержка HTML и CSS**: Возможность использования HTML и Tailwind CSS для создания стильных страниц
- **Frontmatter**: Поддержка метаданных для управления настройками страницы
- **Vue.js интеграция**: Возможность использования Vue.js компонентов внутри Markdown
- **Клиентский рендеринг**: Быстрая загрузка и отображение контента в браузере
- **Готовые к публикации материалы**: Каждая папка с материалами автоматически готова к публикации как полноценный веб-сайт
- **Интеграция с ИИ**: Встроенный помощник с искусственным интеллектом для генерации контента и автодополнения

## Уровни функциональности

### Простой
- Древовидные заметки с поддержкой **markdown**
- Визуальный редактор с **wysiwyg** режимом
- Идеально подходит для **заметок, статей, документации и книг**

### Продвинутый
- Поддержка **html и tailwindcss** для создания стильных и современных страниц
- **frontmatter** для управления метаданными и настройками страницы
- Заметки превращаются в **красивый веб-ресурс** с удобной навигацией и адаптивным дизайном

### Профессиональный
- Реактивность и управление динамическими данными с помощью **vue**
- Интеграция **сторонних библиотек** для расширения функциональности
- Разработка **сложных веб-приложений** прямо в редакторе

## Технологии

- **Vue 3** - современный фреймворк для создания пользовательских интерфейсов
- **Vue Router** - маршрутизация для одностраничных приложений
- **UnoCSS** - мгновенно настраиваемый CSS-фреймворк
- **Element Plus** - библиотека компонентов для Vue
- **@vueuse/core** - набор полезных функций для Vue
- **Markdown парсер** - для обработки Markdown-контента

## Использование

Skald позволяет создавать структурированные документы в привычном древовидном формате. При этом каждая папка с вашими материалами автоматически готова к публикации как полноценный веб-сайт. Достаточно скопировать её на любой статический хостинг - и ваш контент мгновенно доступен в виде сайта без каких-либо дополнительных преобразований или настроек.

## Вопросы и ответы

#### Чем Skald отличается от других редакторов Markdown?
Skald использует подход клиентского рендеринга (CSR), что позволяет создавать интерактивные веб-приложения прямо в редакторе, с поддержкой Vue.js компонентов и других продвинутых возможностей.

#### Можно ли использовать Skald офлайн?
Да, Skald можно использовать в автономном режиме после первоначальной загрузки приложения.

#### Какие операционные системы поддерживает Skald?
Skald доступен для Windows, macOS, Linux и в виде веб-приложения.
